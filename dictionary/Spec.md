一份描述跨多個[工作階段](./Session.md)工作的[交接文件](./Handoff%20artifact.md)（Handoff Artifact）——記錄正在構建的是什麼，而非每個工作階段如何完成各自的份額。隨著工作進展而演進。由[任務單](./Ticket.md)（Tickets）組成。

*情境例句：*

「這些應該全放在一個工作階段裡嗎？」
"Should this all be one session?"

「不，把它整理成規格書——拆分成任務單，每張任務單用獨立的工作階段跑。試圖在單一[脈絡](./Context.md)裡完成整件事，還沒跑到一半就會碰到[混沌區](./Smart%20zone.md)。」
"No, write it up as a spec — break it into tickets, run each one in its own session. Trying to do the whole thing in a single [context](./Context.md) will hit the [dumb zone](./Smart%20zone.md) before you're halfway."
